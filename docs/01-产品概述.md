# LinkNest — 产品概述

> 本文只说明产品做什么、边界是什么。具体需求、技术概括、验收标准和验证记录见 [02-需求文档.md](./02-需求文档.md)，需求级变化见 [03-变更日志.md](./03-变更日志.md)。

- 更新日期：2026-10-02

## 1. 产品目标

LinkNest 让身边的人通过手机热点组成临时局域网，互传原始图片和视频。Host 手机创建空间、保存所有文件；访客优先使用 LinkNest App，无法安装 App 时使用浏览器备用入口。

适合旅行、聚会等多人近距离分享场景。核心体验是：连接同一局域网后发现或扫码加入、原文件传输、不依赖公网账号或第三方云盘。

## 2. 角色与流程

- **Host**：创建空间、开启热点和本地服务、展示入网二维码与空间二维码、接收并保存文件。
- **App 访客**：Android 在 App 内扫描 Wi-Fi 码连接热点；iPhone 暂用系统相机扫码加入热点，返回 App 扫空间码。访客可上传媒体、浏览内容并保存原文件；手动连接 Wi-Fi 仍可使用。
- **Web 访客**：完成基础上传、浏览和单文件下载，作为无法安装 App 时的备用方式。

典型流程：Host 创建空间 → 访客连接热点 → App 发现运行中的空间或扫码加入 → 上传或浏览媒体 → Host 停止共享。

### Host 创建空间网络方案总纲

Host 创建新空间或继续共享历史空间时，统一按以下优先级准备局域网：

1. **临时自动热点优先**：Android 先启动 LinkNest 临时热点并使用其实际有效局域网地址。iOS 不具备由 App 自动开启个人热点的能力；检测到系统个人热点对应接口和地址时优先使用。
2. **当前 Wi-Fi 回退**：Android 临时热点启动失败或未取得有效地址时，改用当前 Wi-Fi；iOS 未检测到个人热点时使用当前 Wi-Fi。iOS 总是提示 Host 手动输入 Wi-Fi 名称和密码；Android 只有在系统无法取得名称或密码时提示补齐。凭据只用于本次运行中的访客连接二维码，不持久化。访客扫描 Wi-Fi 码入网后，再扫描空间码进入空间。
3. **手动热点兜底**：没有可用 Wi-Fi 时提示 Host 到系统设置手动开启个人热点，返回 LinkNest 后点击“确认已开启，重新检测”。检测失败时可继续重试或退出创建；检测成功后要求输入热点名称和密码生成二维码，再启动空间并进入二维码引导页。

所有平台都使用实际检测到的有效私有 IPv4 地址，绑定服务、空间二维码和局域网发现；不得用固定地址替代检测结果。平台能力造成的热点行为差异不得改变“自动热点优先、Wi-Fi 回退、手动热点兜底”的 Host 创建总纲。
## 3. 产品边界

- 只接收可识别的图片和视频，其他文件直接拒绝，避免占用 Host 存储和处理资源。
- 原文件按字节保存，不压缩、不转码；缩略图和预览仅用于界面显示。
- 所有设备必须处于同一局域网。V1.x 不提供互联网中继、账号体系和跨网络同步。
- Host 是当前空间的数据中心；Guest 不能查看 Host 上未共享的历史内容。
- Web 入口不承担完整 App 能力：不上传 Live Photo、不批量保存，不能在线播放视频，也不保证浏览器能预览所有编码。
- Guest App 普通视频支持点击后在线播放；无法播放时可完整下载并保存到系统相册。
- “Host 可选上传到自建云平台”仅为候选需求，不属于当前版本。

## 4. 当前产品决定

- **App 优先，Web 备用**：Host 和访客都使用 App 时体验最完整。
- **界面方向**：App 保留青绿色与深浅主题，分批使用 Forui；Web 保持现有界面。原有功能和媒体操作保持可用。
- **星型结构**：所有传输经过 Host，便于统一索引、校验和恢复。
- **两个二维码**：Wi-Fi 码用于入网；空间码供 Web、发现失败或手动加入时使用。
- **局域网发现与 HTTP**：V1.2 通过 REQ-F003 重设计同一局域网内的 mDNS/DNS-SD 空间发现：Guest 自动发现并核验运行中的空间，用户选择后加入；空间码作为兜底。Web 使用空间凭证建立会话。
- **原文件优先**：上传、下载和保存保持原始字节，预览失败不影响原文件传输。
- **Live Photo 是一个媒体项**：照片和配对视频共同上传、下载、保存和删除；界面标记为 `Live`。
- **版本号管理**：M3 之后的工作按版本号规划，不再新增 M 阶段。

## 5. 平台约束

### iOS

- App 不能可靠地创建、控制或检测个人热点，Host 必须按引导手动开启热点。
- 共享依赖前台运行；锁屏、切后台或系统调度可能暂停本地服务。
- 局域网访问、照片读取和相册保存必须遵守系统权限。

### Android

- Android 8.0 及以上可通过 `LocalOnlyHotspot` 创建临时热点，但系统仍可能回收热点。
- Host 运行期间使用前台服务并保持屏幕唤醒，降低系统终止服务的概率。
- 不同厂商的省电和热点策略差异较大，旧设备尤其需要真机验证。
