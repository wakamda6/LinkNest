## 1. 1.0.0：产品基线

### REQ-0001 · Host 创建局域网空间

- **类型**：新增　**状态**：开发完成
- **当前需求**：Android/iOS 手机可作为 Host，在实际可用的私有局域网地址上创建空间并运行本地 HTTP 服务。
- **技术概括方案**：Dart `HttpServer` 绑定选定的 RFC 1918 IPv4 和 8080 端口；移动端不监听无关网卡。
- **验收标准**：有效地址可创建；端口占用或无地址时不进入共享；停止后释放服务和网络资源。
- **变更原因与历史决定**：热点单一路径已扩展为 REQ-1205、REQ-1206 的网络回退。
- **验证记录**：Android/iOS Host 创建、停止及 V1.2 网络场景已有真机记录。

### REQ-0002 · 邀请、鉴权与空间码

- **类型**：新增　**状态**：开发完成　**依赖**：REQ-0001
- **当前需求**：访客凭邀请加入，未持有空间访问密钥的请求不能访问空间内容。
- **技术概括方案**：空间密钥随空间持久化，恢复时沿用；每次共享新建会话 ID。App 使用 Bearer，Web 将 fragment 密钥换成 `HttpOnly; SameSite=Strict` Cookie。
- **验收标准**：有效邀请可加入，错误密钥被拒绝；恢复空间后密钥稳定、会话更新；日志无密钥和完整 URL。
- **变更原因与历史决定**：旧文档“每次创建更换令牌”已按源码纠正。
- **验证记录**：App/Web 鉴权、握手和历史恢复已有自动检查及真机记录。

### REQ-0003 · 原文件安全上传与落盘

- **类型**：新增　**状态**：开发完成　**依赖**：REQ-0001、REQ-0002
- **当前需求**：只接收允许的图片和视频，保持原始字节，完整校验后安全提交到 Host。
- **技术概括方案**：流式写 `.part` 并计算 SHA-256；普通文件判重。单文件/请求 10 GiB、保留 512 MiB、每请求 20 文件、全局 4 个上传请求，事务恢复隔离残留。
- **验收标准**：摘要一致才落盘；格式、容量或中断失败不生成有效记录；原文件不被预览处理改变。
- **变更原因与历史决定**：把容量、并发、判重和事务边界纳入需求。
- **验证记录**：上传、限制、摘要、事务恢复和 Live Photo 成对提交有自动检查。

### REQ-0004 · 共享画廊与预览

- **类型**：新增　**状态**：开发完成　**依赖**：REQ-0003
- **当前需求**：Host、Guest App 和 Web 可浏览当前空间媒体及平台支持的预览。
- **技术概括方案**：缩略图最长边 512 px，预览最长边 2000 px；派生资源独立于原文件，API 只暴露公开字段。
- **验收标准**：新增媒体最终出现；预览失败仍可下载原文件；其他空间和未共享文件不可见。
- **变更原因与历史决定**：排序、缓存和大图由 REQ-1018、REQ-1021、REQ-1203 扩展。
- **验证记录**：App/Web 画廊与预览已有自动检查和真机记录。

### REQ-0005 · Guest 传输与连接恢复

- **类型**：新增　**状态**：开发完成　**依赖**：REQ-0002、REQ-0003
- **当前需求**：Guest 可上传、下载、保存、取消，并在短暂断线或前后台切换后安全恢复。
- **技术概括方案**：Guest 串行上传；失败项保留待重试。恢复时重建客户端，先试历史地址再试网关候选，并核对空间 ID。
- **验收标准**：成功文件摘要一致；取消清理部分文件；不能误入其他空间；前台可继续待重试项。
- **变更原因与历史决定**：后台和地址恢复由 REQ-1012 细化。
- **验证记录**：传输、取消、断线和错误空间拒绝已有自动检查；iOS 恢复真机通过。

### REQ-0006 · Web 备用入口

- **类型**：新增　**状态**：开发完成　**依赖**：REQ-0002～REQ-0005
- **当前需求**：无法安装 App 时可用浏览器上传普通媒体、浏览画廊和下载单个资源。
- **技术概括方案**：Host 提供 Vue 内置资产；Web 以 Cookie 会话访问 API，逐文件上传并轮询画廊。
- **验收标准**：可建立会话、上传、预览和下载；不创建 Live Photo、不批量保存、不在线播放原视频。
- **变更原因与历史决定**：Web 保持备用入口定位。
- **验证记录**：Web 测试、构建及 Safari/Chrome 真机流程通过。

### REQ-0007 · Host 生命周期与异常恢复

- **类型**：新增　**状态**：开发完成　**依赖**：REQ-0001
- **当前需求**：Host 管理服务、网络、广告、在线成员和关闭保护，并明确平台后台限制。
- **技术概括方案**：Android 使用前台服务和屏幕常亮并轮询健康状态；iOS 网络失效时暂停广告、回前台恢复；资源按逆序清理。
- **验收标准**：启动失败可重试；在线访客受关闭保护；停止释放全部资源；异常有可见提示。
- **变更原因与历史决定**：强制关闭和热点恢复由 REQ-1010、REQ-1015 扩展。
- **验证记录**：生命周期、前台服务及真机关闭流程已有通过记录。

### REQ-0008 · Live Photo 单媒体项

- **类型**：修复　**状态**：开发完成　**依赖**：REQ-0003～REQ-0005
- **当前需求**：照片和配对视频作为一个 Live Photo 上传、显示、保存和删除；iOS 与可播放配对视频的 Android 设备支持长按播放。
- **技术概括方案**：两资源一次逻辑提交并保存配对；iOS 原生播放/保存，Android 长按播放配对视频，不支持播放的设备保留静态预览和两份原资源；Web 静态预览。
- **验收标准**：资源完整才标记 Live；支持播放的平台长按播放、松手停止，Android 设备无法解码时仍显示静态图；删除时配对和缓存共同删除；失败明确提示。
- **变更原因与历史决定**：修复 iOS 误判、通道漏传配对视频及多图播放控制；REQ-1302 补充 Android 播放体验。
- **验证记录**：用户确认 iOS 多张 Live Photo 上传、重进和播放通过；2026-10-18 用户确认 Android 长按播放真机测试通过。

### REQ-0009 · 媒体格式能力分级

- **类型**：新增　**状态**：开发完成　**依赖**：REQ-0003、REQ-0004
- **当前需求**：按格式和平台能力分为完整预览、基础预览、只传输或拒绝。
- **技术概括方案**：服务端校验类型并保留原字节；预览按平台能力生成，方向由 REQ-1017 处理。
- **验收标准**：支持格式可预览保存；只传输格式可上传下载；非图片视频被拒绝；错误原因清晰。
- **变更原因与历史决定**：浏览器能否解码不等同于能否传输。
- **验证记录**：常见图片、视频、HEIC 和 Live Photo 已跨平台验证。

### REQ-1014 · 安全连接诊断日志

- **类型**：新增　**状态**：开发完成　**依赖**：REQ-0005
- **当前需求**：Guest DEBUG 日志记录连接状态、失败次数和安全原因码。
- **技术概括方案**：只记状态、类别和计数，不记令牌、密码、完整 URL、文件名、空间名或精确位置。
- **验收标准**：断开、恢复和失败可定位；日志无敏感字段。
- **变更原因与历史决定**：无 ID 的通用日志维护记录已删除，只保留本需求范围。
- **验证记录**：自动日志检查通过；历史 Guest 真机采集不完整，不影响开发状态。

### REQ-1015 · Android 临时热点异常恢复

- **类型**：修复　**状态**：开发完成　**依赖**：REQ-0007
- **当前需求**：热点启动、停止、重复回调或系统回收时保持一致；意外停止提示 Host 并只自动恢复一次。
- **技术概括方案**：进程级持有 reservation；原生请求只回复一次；再次失败显示全局重试；关闭接口按 Android 版本保护。
- **验收标准**：失败可重试；异常立即提示；最多自动恢复一次；迟到回调不崩溃；最低版本无高 API 调用。
- **变更原因与历史决定**：连续修复回调崩溃、reservation 生命周期、全局提示和 `NewApi`。
- **验证记录**：自动检查、Debug 构建、App lint、停止和首次恢复记录通过；厂商差异持续回归。

### REQ-1016 · Web 预览增量刷新

- **类型**：修复　**状态**：开发完成　**依赖**：REQ-0004、REQ-0006
- **当前需求**：Web 刷新时保持已有预览，新媒体预览就绪后自动显示。
- **技术概括方案**：按文件 ID 合并轮询结果，只在展示字段或预览状态变化时更新 URL。
- **验收标准**：旧图不闪烁；新媒体无需整页刷新即可出现缩略图。
- **变更原因与历史决定**：替代整表更新造成的重复加载。
- **验证记录**：`npm test` 和两种真机刷新场景通过。

### REQ-1017 · 图片 EXIF 方向

- **类型**：修复　**状态**：开发完成　**依赖**：REQ-0004、REQ-0009
- **当前需求**：两平台 Host 生成预览时应用 EXIF 旋转和镜像，原文件不变。
- **技术概括方案**：Android 读取 EXIF；iOS 使用 ImageIO 在目标尺寸应用方向。
- **验收标准**：竖拍和镜像照片在 App/Web 方向正确；下载字节不变。
- **变更原因与历史决定**：Android 修复后补齐 iOS 同等能力。
- **验证记录**：用户确认 iOS 通过，Android 有自动检查。

## 2. 1.1.0：历史空间与体验完善

### REQ-1101 · 空间、会话与文件归属模型

- **类型**：新增　**状态**：开发完成
- **当前需求**：用稳定空间、每次共享会话和文件归属表达多次相聚并隔离数据。
- **技术概括方案**：`state.json` 保存 `Space`、`SharingSession`、`FileRecord`；空间 ID/密钥稳定，会话 ID 每次更新。
- **验收标准**：不同空间隔离；恢复空间时 ID 不变且新建会话；公开 API 不泄露内部字段。
- **变更原因与历史决定**：替代 V1.0 单空间索引。
- **验证记录**：自动测试及 2026-09-24 Android 多空间、重进通过。

### REQ-1102 · 状态持久化与中断恢复

- **类型**：新增　**状态**：开发完成　**依赖**：REQ-1101
- **当前需求**：空间、会话、文件、预览和事务实时安全落盘，异常退出后恢复一致状态。
- **技术概括方案**：版本化 `state.json` 原子写入并保留 Windows 备份；启动关闭开放会话，恢复上传/删除事务并隔离孤立文件。
- **验收标准**：正常停止有结束状态；异常后已提交文件保留；损坏主文件可恢复；部分事务不冒充完整文件。
- **变更原因与历史决定**：旧 `index.json` 只用于 REQ-1107 迁移。
- **验证记录**：状态和事务自动测试、Android 正常停止与重进通过。

### REQ-1103 · Host 历史入口与继续共享

- **类型**：新增/修改　**状态**：开发完成　**依赖**：REQ-1101、REQ-1102
- **当前需求**：Host 从统一历史入口查看全部空间并按最近活动排序、选择继续共享。
- **技术概括方案**：继续时沿用空间 ID、名称和密钥并创建新会话；入口在首页右上角。
- **验收标准**：所有空间可见；继续不会混入其他文件；运行中空间可只读查看。
- **变更原因与历史决定**：早期“72 小时内标记最近”未实现，已移出当前要求。
- **验证记录**：V1.1 Android 继续共享、V1.2 首页入口验收通过。

### REQ-1104 · Host 历史浏览

- **类型**：新增　**状态**：开发完成　**依赖**：REQ-1101、REQ-1102、REQ-1107
- **当前需求**：按空间、日期、小时和文件浏览历史，并显示时间、数量、占用和可用地点；历史空间列表显示为与详情日期分组一致的圆角卡片，日期与小时折叠卡片底部不出现多余横线。
- **技术概括方案**：由状态仓库按本地时间分组；共享中只读，停止后开放删除；列表项复用详情页的柔和背景容器，保留原有操作按钮。
- **验收标准**：文件归组正确；空空间有提示；运行中浏览不影响共享；发起者和参与者空间均显示为圆角卡片且操作可用；日期与小时折叠卡片底部无重复分隔线。
- **变更原因与历史决定**：将单一当前空间扩展为本地档案；REQ-1302 去除嵌套折叠组件的两条默认分隔线，并按用户后续确认将详情日期分组的卡片容器用于历史空间列表，保留原版按钮。
- **验证记录**：历史浏览自动检查及 2026-09-26 Android 真机通过；2026-10-17 Android 截图定位到两条分隔线来自日期与小时折叠组件，界面测试确认两条分隔线已设为透明；历史空间列表改用圆角背景后，列表与首页相关 13 项测试、静态分析及 Android Debug APK 构建通过。用户确认列表卡片、详情页分隔线真机测试通过。

### REQ-1105 · GPS 地点与系统地理编码

- **类型**：新增/修改　**状态**：开发完成　**依赖**：REQ-1104
- **当前需求**：有 GPS 时尽量显示省/州起始地点；无 GPS、拒权或系统编码不可用不影响上传。
- **技术概括方案**：Android ExifInterface、iOS ImageIO 读取坐标，调用系统反向地理编码并缓存；位置不进入 Guest/Web API 或日志。
- **验收标准**：服务可用时显示地点；失败时显示缺省状态且上传成功；同批照片不反复扫描。
- **变更原因与历史决定**：未引入第三方/离线编码，按当前系统能力界定完成范围。
- **验证记录**：用户确认 Android、iOS 通过；Android 9 或部分旧机缺少系统能力时无法显示地点。

### REQ-1106 · 历史删除与事务保护

- **类型**：新增　**状态**：开发完成　**依赖**：REQ-1101、REQ-1102、REQ-1104
- **当前需求**：停止共享后可删除文件、日期组或空间；共享中禁止删除；连续删除同一小时的文件时保留展开状态。
- **技术概括方案**：事务共同删除原文件、Live Photo 配对资源、缓存和状态，中断后可收敛。
- **验收标准**：范围准确；Live Photo 无单边残留；共享中拒绝；重启后磁盘和状态一致；连续删除同小时文件无需重新展开。
- **变更原因与历史决定**：避免只删索引或文件；REQ-1302 修复删除后菜单折叠。
- **验证记录**：删除事务自动测试、Android 及用户确认的 iOS 真机通过；REQ-1302 连续删除展开状态自动测试通过，用户确认连续删除时小时列表保持展开的真机测试通过。

### REQ-1001 · Guest 参与历史

- **类型**：新增/修改　**状态**：开发完成　**依赖**：REQ-1101、REQ-1202

- **验证记录**：Android 重进及用户确认的 iOS 历史、删除通过。

- **技术概括方案**：普通图片沿用内存 LRU，并把缩略图和最长边 2000 px 预览原子写入磁盘，不自动缓存原图；Live Photo 把照片和配对视频校验后作为一个逻辑项提交。缓存按空间 ID、文件 ID、资源角色和摘要隔离，使用 4 GiB 总预算、至少 1 GiB 可用空间保护、LRU 淘汰和在用租约。升级兼容读取旧图片与 Live Photo 条目，并删除旧普通视频分块、连续文件及索引状态。
- **验收标准**：普通图片在内存冷但磁盘命中时不访问 Host，摘要变化或删除后失效；Live Photo 双资源只整体命中，反复开关、重进空间和 App 重启后不重新下载；普通独立视频不创建磁盘缓存、回环代理或本地播放源；跨空间、同名空间或摘要变化不能误命中；4 GiB 容量、1 GiB 余量、LRU、租约、残留与损坏状态可恢复；升级删除旧普通视频缓存且保留图片与 Live Photo 缓存；删除参与历史只清理对应缓存；缓存异常不影响查看、播放和保存；产品中不出现离线画廊、缓存浏览入口或普通图片原图自动收藏。
- **变更原因与历史决定**：真机发现 Live Photo 离页即删除临时资源，最初也为普通视频增加字节缓存；普通视频先后尝试 1 MiB 物理分块、约 8 MiB 预读窗口和连续文件完整命中，但大视频真机效果仍不理想。用户决定撤销普通视频磁盘缓存并恢复 REQ-1008 的 Host Range 在线播放，只保留图片与 Live Photo 性能缓存；仍拒绝“在线播放同时后台完整下载”的双流方案和离线画廊。
- **验证记录**：缓存定向 8 项测试通过，覆盖图片与 Live Photo 缓存、容量租约、v1 `videoBlock` 清理及 v2 连续视频文件删除并迁移到 v3；数据源与画廊测试确认普通视频不再使用回环代理或本地播放源。Host App 全量 181 项测试、静态分析及 Android Release APK 构建通过；Windows 环境未执行 iOS 构建，既有 iOS 图片与 Live Photo 真机结果仍有效。

### REQ-1302 · 优化空间发现与浏览体验

- **类型**：优化/修复　**状态**：开发完成　**依赖**：REQ-0008、REQ-1019、REQ-1104、REQ-1106
- **当前需求**：加快局域网空间发现；Android Live Photo 尽可能支持长按播放；发现空间后直接进入；历史空间连续删除不收起小时列表；去除历史详情折叠卡片底部的两条横线，并让历史空间列表使用相同的圆角卡片容器。
- **技术概括方案**：首页扫描间隔从 10 秒经 5 秒缩短到 3 秒，Host 广告仍按空间启动及必要恢复注册；发现后显示连接状态并直接打开画廊，失败可重试或扫码；Android 用已保存的配对视频长按播放，设备无法播放时保留静态预览；历史列表保留小时展开状态，关闭日期与小时折叠组件的默认分隔线；空间列表复用详情日期分组容器，保留原版操作按钮。
- **验收标准**：首页初显、回前台及约每 3 秒搜索，扫描未结束时不并发启动；点选已发现空间不露出扫码页，连接失败可重试或扫码；支持配对视频的 Android 设备长按播放、松手停止，不支持时仍可查看静态图；删除一个文件后同小时剩余文件保持可见；历史详情折叠卡片底部无两条横线；历史空间列表以圆角卡片展示且原有操作正常。
- **变更原因与历史决定**：针对用户在 iOS、Android 真机发现的五处体验问题合并优化；不以电量限制扫描频率；用户确认 5 秒版发现速度有效后，要求进一步缩短为 3 秒。
- **验证记录**：历史空间连续删除及 Android/iOS 发现后连接路径定向自动测试通过；相关 43 项测试、`flutter analyze` 与 Android Debug APK 构建通过。Android 截图确认双横线来自日期和小时组件，修复后历史界面 13 项测试及静态分析通过；列表圆角卡片调整后，列表与首页相关 13 项测试、静态分析及 Android Debug APK 构建通过。用户确认历史空间列表卡片、5 秒版空间发现速度和 Android Live Photo 长按播放真机通过；2026-10-18 进一步确认 3 秒版发现速度、Android/iOS 发现后直接进入空间、历史详情页分隔线和连续删除展开状态均通过真机测试。Windows 环境未执行 iOS 构建。

### REQ-1303 · 发起者空间画廊播放视频

- **类型**：新增　**状态**：开发完成，真机验证通过　**依赖**：REQ-1008
- **当前需求**：发起者在自己的空间画廊打开视频大图后，可以直接播放本人或访客上传的视频。

- **验证记录**：发起者播放访客上传视频的控件测试通过，覆盖本地原文件、重播、切页暂停和播放器释放；此前画廊与首页相关 28 项测试、Android Debug APK 构建通过。2026-10-18 用户确认 Android 发起者播放通过；iOS 初次测试失败后，扩展名硬链接修复的画廊相关 19 项测试和 `flutter analyze` 通过，用户再次确认 iPhone 发起者播放视频正常。Windows 环境未执行 iOS 构建。
