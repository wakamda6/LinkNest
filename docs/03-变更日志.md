# LinkNest — 变更日志

> 本文只记录需求级变化。每条必须带稳定需求 ID，只说明该需求新增、修改或修复了什么；技术方案、验收标准和验证结果见 [02-需求文档.md](./02-需求文档.md)。版本规则见 [06-版本管理.md](./06-版本管理.md)。

## [1.3.0] - 2026-10-18

### Added

- `REQ-1301` 增加 Guest 按空间的图片预览与 Live Photo 双资源性能缓存，可在重进同一空间后复用并随本机参与历史删除而清理。
- `REQ-1302` 优化空间发现、已发现空间进入、Android Live Photo 播放，以及历史空间圆角卡片、详情和连续删除体验。
- `REQ-1303` 发起者空间画廊支持直接播放本人和访客上传的视频。

### Fixed

- `REQ-1303` 修复 iOS 发起者播放无扩展名本地视频时初始化失败。

### Changed

- `REQ-1302` 首页空间发现扫描间隔缩短至 3 秒。
- `REQ-1008` 普通视频恢复直接使用 Host Range 在线播放，不再经过本机回环缓存代理或读取本地缓存文件。
- `REQ-1301` 缓存范围收口为图片与 Live Photo，升级时删除旧普通视频磁盘缓存并保留其他有效缓存。

## [1.2.0] - Unreleased

### Added

- `REQ-1201` 增加 Android App 内扫码入网和 iPhone 系统相机入网流程，保留手动连接兜底。
- `REQ-1203` 增加空间内稳定上传归属，App 画廊按别人优先、本人置后显示并保持昵称稳定。
- `REQ-1204` 增加青绿色 LinkNest 图标并应用到 Android、iOS、首页和关于页。

### Fixed

- `REQ-0008` 修复 iOS Live Photo 识别、配对资源传递和多图画廊长按播放。
- `REQ-1012` 修复 iOS Host 从后台恢复后 Bonjour 注册失效导致 Guest 无法重新发现和进入空间的问题。
- `REQ-1015` 修复 Android 最低支持版本关闭热点时调用高版本 API 的兼容问题。
- `REQ-1206` 修复热点/Wi-Fi 凭据被旧编辑流程写入本地偏好的问题，升级时清除历史残留值并删除无用编辑入口。

### Changed

- `REQ-1001` Guest 参与历史取消最近 5 条限制，保留全部成功加入记录，并可只删除本机参与记录。
- `REQ-1019` 自动发现改为非阻塞流程，Guest 在首页和加入页核验一个或多个空间后自行选择进入。
- `REQ-1021` 统一 App 大图黑底、控件、高清图衔接和开关转场，并适配减少动画。
- `REQ-1105` 地点能力按系统反向地理编码的实际边界收口；旧 Android 缺少系统能力时允许不显示地点且不阻塞上传。
- `REQ-1202` 使用 Forui 统一 App 首页、创建、二维码、画廊、设置、历史、主题、动效和可访问性，Web 界面保持现状。
- `REQ-1205` Host/Guest 地址处理统一接受三个 RFC 1918 私网段，恢复 `10/8`，并按实际接口绑定服务、二维码和广告。
- `REQ-1206` Host 采用 Android 临时热点→Wi-Fi→手动热点、iOS 个人热点→Wi-Fi→手动热点回退；凭据可填写或跳过且仅保留当前运行态。
- `REQ-F003` 局域网发现重设计为 Android 原生 NSD 与 iOS 接口绑定 DNS-SD，Guest 通过 `/api/discovery` 核验，扫码作为兜底。

## [1.1.0] - Unreleased

### Added

- `REQ-1001` 增加 Guest 成功加入空间的历史记录和旧地址空间 ID 校验。
- `REQ-1003` 增加 Guest 随机昵称，随后扩展为同一空间内稳定身份。
- `REQ-1004` 增加热点名称、密码和空间地址长按复制。
- `REQ-1005` 明确 Android 普通应用不读取或控制受限的系统个人热点凭据。
- `REQ-1008` 增加带鉴权 HTTP Range 的 App 视频在线播放、重播和会话复用。
- `REQ-1019` 增加运行空间的 DNS-SD/Bonjour 自动发现，后在 V1.2 由 REQ-F003 重设计。
- `REQ-1101` 增加空间、共享会话和文件归属模型。
- `REQ-1102` 增加版本化 `state.json`、原子保存和异常事务恢复。
- `REQ-1103` 增加 Host 历史空间入口和继续共享。
- `REQ-1104` 增加按空间、日期、小时和文件浏览 Host 历史。
- `REQ-1105` 增加照片 GPS 私有元数据、系统反向地理编码和本地结果复用。
- `REQ-1106` 增加文件、日期组和空间的事务化删除。

### Fixed

- `REQ-1007` 修复 Guest 未连接 Wi-Fi 时扫码相机反复创建造成的闪烁。
- `REQ-1015` 修复 Android 临时热点 reservation 生命周期、异常停止通知和一次自动恢复。
- `REQ-1017` 修复两平台生成预览时没有完整应用 EXIF 旋转和镜像的问题。

### Changed

- `REQ-1002` 空间改名改为持久化并同步 HTTP 元数据、发现广告、Guest 标题和历史名称。
- `REQ-1006` Android 改为只使用 App 临时热点，删除热点模式选择和持久化设置，保留运行态只读二维码。
- `REQ-1009` App 图片大图增加焦点缩放并在放大时锁定翻页。
- `REQ-1010` Host 增加长按 5 秒并二次确认的强制关闭入口。
- `REQ-1011` Guest 顶栏增加退出确认和上传入口并适配窄屏。
- `REQ-1012` Guest 前后台恢复改为重建客户端、核对空间并重试保留传输，Android 使用前台服务，iOS 到期安全取消。
- `REQ-1013` Web 大图改用 Swiper Vue/Zoom，增加明确关闭、可靠横滑和连续双指缩放。
- `REQ-1018` App 文件轮询改为增量合并并复用未变化的缩略图和预览。
- `REQ-1020` 新建空间名称改为独立空白草稿，恢复历史空间使用独立入口。
- `REQ-1021` App 图片查看改用 `photo_view` 统一缩放、翻页和当前图片 Hero。
- `REQ-1107` 首次升级把 V1.0 `index.json` 中的媒体安全迁移到“旧版空间”。

## [1.0.0] - Unreleased

### Added

- `REQ-1014` 增加不含敏感信息的 Guest 连接状态、失败次数和原因码日志。

### Fixed

- `REQ-1015` 修复 Android LocalOnlyHotspot 失败、停止、重复或迟到回调造成的失效状态和崩溃。
- `REQ-1016` 修复 Web 自动刷新时重复加载已有预览以及新媒体缩略图不能自动出现的问题。
- `REQ-1017` 修复 Android Host 生成预览时未应用 EXIF 方向的问题。
