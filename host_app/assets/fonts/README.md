# 画廊字体

- `Lora.ttf`：[Google Fonts / Lora](https://github.com/google/fonts/tree/main/ofl/lora)，用于画廊拉丁标题。
- `Raleway.ttf`：[Google Fonts / Raleway](https://github.com/google/fonts/tree/main/ofl/raleway)，用于画廊拉丁正文。
- 对应的 `*-OFL.txt` 为原始字体许可，随 App 打包并登记到 Flutter 许可列表。
- 两套字体不提供中文字形；中文由 Android/iOS 系统字体回退显示。字体全部本地打包，运行时不联网加载。
