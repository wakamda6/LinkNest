# LinkNest 隐私声明

更新日期：2026 年 11 月 9 日

本声明适用于 LinkNest Android 和 iOS App、App 提供的局域网浏览器入口，以及 LinkNest 宣传网站。

## 局域网共享

LinkNest 通过手机热点或同一 Wi-Fi 创建共享空间。你选择上传的照片、视频及文件名等信息，通过局域网发送至发起者设备。获准加入空间的参与者可以浏览或保存已共享的媒体。传输使用局域网 HTTP 和空间凭证，原始文件可能保留拍摄时间、位置等元数据。请只在信任的网络和参与者之间共享二维码、空间码和媒体。

App 无需注册公网账号，媒体传输不经过开发者服务器。App 不集成广告、使用分析或崩溃上报服务。

## 设备权限及用途

- 局域网、Wi-Fi 和附近设备权限用于创建热点、发现空间或连接共享网络。部分旧版 Android 会以位置权限提供这些 Wi-Fi 功能，LinkNest 不使用它进行位置追踪。
- 相机用于在设备上识别 Wi-Fi 和空间二维码。
- 照片和视频访问用于读取你选择共享的媒体，在支持的平台上也用于读取 Live Photo 的配对视频。Android 可能请求媒体位置信息权限，以读取未移除元数据的原始文件。相册写入权限用于保存你选择保留的照片和视频。
- Android 通知用于显示共享正在运行。你可以在系统设置中管理权限，相关功能可能随权限关闭而受限。

## 本地保存和删除

发起者设备保存空间记录、上传文件和相关元数据。关闭共享后，发起者仍可在历史记录中查看、删除文件或删除空间。访客 App 在本机保存参与记录和媒体缓存，可通过删除参与记录清理该记录及对应缓存。

App 在本机生成并保存随机安装标识，用于局域网共享中的上传归属。已保存到系统相册、下载目录或其他参与者设备的副本由持有者管理，需要在对应位置删除。

## 宣传网站和 GitHub

宣传网站不加载广告或访问统计脚本。网站服务器为运行维护与排障记录常规访问日志，包括连接来源 IP、请求时间、请求路径、响应状态和浏览器标识等。Nginx 访问日志按日轮转，最多保留最近 14 份轮转日志。

Android 下载、开源代码和问题反馈由 GitHub 提供。访问这些链接后，GitHub 依据其自身的隐私规则处理相关访问和下载。

## 联系维护者

如对隐私或本地数据删除有疑问，可通过 [LinkNest GitHub Issues](https://github.com/wakamda6/LinkNest/issues) 联系维护者。Issues 是公开页面，请勿附上个人资料、原始媒体、空间凭证或热点密码。安全漏洞可通过[仓库安全说明](https://github.com/wakamda6/LinkNest/blob/main/SECURITY.md)中的渠道报告。
